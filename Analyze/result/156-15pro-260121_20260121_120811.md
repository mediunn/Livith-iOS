## 6. 📚 WWDC25 SwiftUI 성능 핵심 원칙

### View Body 속도 유지
- 60fps 기준 각 View Body는 **16.67ms** 이내 완료 권장
- 비싼 작업(Formatter 생성, 복잡한 계산)은 View Body 외부에서 수행

### 불필요한 업데이트 방지
- @Observable의 세분화된 종속성 설계
- 전체 컬렉션이 아닌 개별 항목에 대한 종속성 사용
- Equatable conformance로 실제 변경 시에만 업데이트

### 데이터 흐름 설계
- 각 View가 필요한 데이터에만 종속되도록 설계
- ViewModel을 통한 데이터 캡슐화
- Environment에 자주 변경되는 값 저장 피하기
