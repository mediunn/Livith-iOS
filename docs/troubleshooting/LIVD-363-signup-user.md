- `docs/plans/LIVD-363-signup-user.md` 계획 문서를 추가하고 커밋을 생성했다.

**문제**
- 커밋 메시지를 `[Docs] LIVD-363: 회원가입 및 유저 모델 수정 계획 추가`로 작성했다.

**해결**
- 트러블슈팅 문서를 추가했다.
- 커밋 메시지를 `[Chore] LIVD-363 - 회원가입 및 유저 모델 수정 계획 추가`로 amend한다.

**교훈**
- 커밋 전에는 최근 히스토리뿐 아니라 `docs/rules/git.md`의 형식을 우선 확인한다.
- 문서 변경 커밋은 허용 타입에 맞춰 `[Chore] 이슈키 - 설명` 형식을 사용한다.
