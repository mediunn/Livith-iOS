# [이슈 미지정] 이슈·PR 작성 규칙 - 트러블슈팅

## 기록

### 2026-11-16 - 템플릿 교체 패치 실패

**상황**
- Git 규칙과 이슈·PR 템플릿을 함께 수정했다.

**문제**
- 패치 도구가 동일 경로의 중복 작업을 거부해 첫 패치가 적용되지 않았다.

**원인**
- 한 패치에서 같은 파일에 삭제와 추가를 동시에 지정했다.

**해결**
- 규칙은 수정 패치로 적용하고 템플릿은 파일 내용을 교체했다.

**교훈**
- 기존 파일 교체는 동일 경로의 삭제·추가 대신 수정 작업을 사용한다.
- 승격 후보: no
