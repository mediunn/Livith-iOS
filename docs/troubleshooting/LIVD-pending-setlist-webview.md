# 셋리스트 WebView 트러블슈팅

## Tuist 의존성 및 실행 권한
- 현상: 샌드박스에서 Tuist 세션 디렉터리 쓰기가 거부되었고, 권한 적용 후 기존 Kakao SDK 체크아웃 경로가 없어 프로젝트 생성이 실패했다.
- 조치: 필요한 권한으로 기존 의존성을 `tuist install`로 복원한 후 프로젝트 생성과 ConcertFeature 빌드가 성공했다.

## 로컬 개발 서버
- 현상: 샌드박스에서 로컬 포트 바인딩이 거부되었다.
- 조치: 필요한 권한으로 개발 서버를 실행했고 앱 진입 경로가 HTTP 200을 반환했다.
