# [LIVD-427] 인스타그램 공유 → 관심 콘서트 등록 화면 구현 - 트러블슈팅

## 기록

### 2026-07-08 12:05 - HomeFeature 전체 테스트에서 선행 실패 1건 발견

**상황**
- 신규 Store 구현 후 회귀 확인을 위해 HomeFeature scheme 전체 테스트(84개)를 실행했다.

**문제**
- `HomeStoreTests`의 "관심 콘서트 정리 정책별 성공 메시지를 설정해야 한다" 테스트 1건이 실패했다. 프로덕션 문구는 "종료·취소된 공연이 자동 정리됐어요", 테스트 기대값은 "취소·종료된 공연이 자동 정리됐어요"로 어순이 불일치한다.

**원인**
- develop 시점부터 존재하던 문구·기대값 불일치. 이번 브랜치는 `HomeStore.swift`와 `HomeStoreTests.swift`를 변경하지 않았다 (git diff로 확인).

**해결**
- 미해결. 이슈와 무관한 변경을 브랜치에 섞지 않기 위해 수정하지 않고 보고만 남긴다. 별도 이슈로 처리 필요.

**교훈**
- 전체 스위트 실패가 나오면 브랜치 diff와 대조해 선행 실패인지 먼저 판별한다.

### 2026-07-08 11:40 - Figma 문서 탭 비활성화로 토스트·팝업 문구 미확보

**상황**
- Store 테스트에 넣을 토스트·중단 팝업 문구를 수집하려고 Figma MCP를 재호출했다.

**문제**
- 세션 초반에는 수집이 됐지만, 도중 Figma Desktop의 활성 탭이 바뀌어 "No node could be found" 오류로 토스트 2종·중단 팝업 문구를 확보하지 못했다.

**원인**
- figma-desktop MCP는 활성 탭의 문서만 조회할 수 있는데, 작업 중 대상 문서가 활성 탭에서 벗어났다.

**해결**
- 확보한 명세(FR 설명)와 화면 문구 기준으로 임시 문구를 상수로 지정하고 진행: 성공 토스트 "[콘서트명] 관심 콘서트로 등록되었어요", 실패 토스트 "관심 콘서트 등록에 실패했어요", 중단 팝업 "관심 콘서트 등록을 그만할까요?" / "지금은 그만할래요" / "잘못 눌렀어요". Figma 재접속 후 대조·교정 필요.

**교훈**
- Figma 수집이 필요한 문구는 세션 초반에 화면·토스트·팝업까지 한 번에 수집해 둔다.

### 2026-07-08 11:20 - 계획 문서에 Figma 링크 기재 지적

**상황**
- 계획 문서 배경에 근거 자료로 Figma 파일 URL(파일 키 포함)을 그대로 기재했다.

**문제**
- 사용자가 계획 문서에 MCP(Figma) 링크를 넣으면 안 된다고 지적했다. 저장소에 커밋되는 문서에 내부 디자인 파일 키가 노출된다.

**원인**
- 커밋 대상 문서와 세션 내부 참조를 구분하지 않고 URL을 그대로 옮겼다.

**해결**
- 계획 문서에서 URL을 제거하고 "Figma 디자인 문서(FR-01~06)"로만 표기했다.

**교훈**
- 저장소에 커밋되는 문서(plans/troubleshooting 등)에는 Figma URL·파일 키·노드 ID 같은 내부 링크를 넣지 않는다. 필요한 참조는 명세 이름(FR 번호)으로 표기한다.
