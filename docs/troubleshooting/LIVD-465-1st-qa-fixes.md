### 2026-07-27 21:36 - 홈 미설정 블록 상단 들뜸·툴팁 잘림

**상황**
- 로고·탭을 black100으로 고정하고 미설정 CTA에 좌측 하단 radius를 준 뒤, 블록이 떠 보이고 노란 툴팁이 잘렸다.

**문제**
- 탭과 CTA 사이에 틈이 보였고, 콜아웃이 블록 밖으로 나가지 못했다.

**원인**
- empty 헤더에도 `padding.top 16`이 남아 black100 간격이 드러났다.
- radius를 `clipShape`으로 걸어 오버레이 툴팁까지 잘렸다.

**해결**
- empty+배너 없음일 때 헤더 top padding 0.
- `UnevenRoundedRectangle`를 background fill로만 적용(clip 제거).

**교훈**
- 배경만 둥글릴 때는 clipShape 대신 shape fill background를 쓴다.
- 승격 후보: no

### 2026-07-27 21:17 - 설정 화면 정보 요청 버튼·툴팁 Figma 정합

**상황**
- 관심 콘서트 설정에 정보 요청 버튼·툴팁을 추가한 뒤, 위치·패딩·화살표·타이포가 디자인과 다르다는 피드백을 받았다. 유저가 PR #298과 Figma `47:3403`/`47:3404`를 참조하라고 했다.

**문제**
- 버튼이 헤더에서 너무 위에 있고, 툴팁 버블·오프셋·화살표(뭉뚝함·가로 위치)·텍스트(색·Bold)가 Figma와 어긋났다.

**원인**
- 인스타 검색·구 상수·`LivithNavigationView` 습관을 그대로 이식했다.
- 화살표는 Figma 메타데이터 trailing≈1을 믿어 우측 끝에 붙었고, 인스타의 apexRadius까지 다시 넣어 꼭짓점이 둥글어졌다. 위치는 trailing 15, 형태는 직선 삼각형.

**해결**
- 네비: top 20, 백 38, 버튼 아이콘 행 세로 중앙.
- 툴팁: bubble 31 / offset 28, `caption1Bold` + `black80`.
- 화살표: 14×8, trailing 15·직선 삼각형·버블과 -2 겹침. 메타데이터 trailing≈1은 무시.
- 가이드/검색 여백: Figma `47:5279` 기준 네비→가이드·가이드→검색 top 30→20.

**교훈**
- 유사 화면 이식 시 인스타/공통 네비 값을 복사하지 말고, 해당 화면 Figma와 최신 QA PR 상수부터 맞춘다.
- 툴팁 화살표는 메타데이터 polygon 좌표가 아니라 렌더·실기기 확인으로 맞춘다.
- 승격 후보: no

### 2026-07-27 20:49 - 요청 결과 공연명 말줄임 기준을 공백 포함 24자로 정정

**상황**
- Figma 플레이스홀더 `[19자 내 공연명 이후 말줄임..] 콘서트`를 목에 넣으니 코드가 19자로 잘라 `..`와 `…`가 겹쳤다.

**문제**
- 말줄임 한도가 19자로 되어 있어 Figma 표기(플레이스홀더 전체 24자)와 어긋났다.

**원인**
- Figma 문구의 `19자`를 한도로 해석했다. 실제 플레이스홀더 문자열 길이는 공백 포함 24자이다.

**해결**
- `requestConcertNameMaxLength`를 24로 변경하고 테스트를 갱신했다. 목 타이틀은 Figma 원문을 유지한다.

**교훈**
- Figma 플레이스홀더 숫자는 한도가 아닐 수 있다. 표시 문자열 길이와 주석을 함께 확인한다.
- 승격 후보: no

### 2026-07-27 20:30 - 취소된 관심 목록 결과가 재조회 로딩을 꺼버리는 순서 버그

**상황**
- 구현 후 코드 점검 중 `_interestListResult` 처리 순서를 검토했다.

**문제**
- `isInterestListRetryLoading = false`를 cancellation 체크보다 먼저 수행하면, 재조회 중 이전 Task 취소 결과가 로딩을 끄고 엠티뷰가 잠깐 보일 수 있다.

**원인**
- 재조회 로딩 해제와 cancellation early return 순서를 분리하지 않았다.

**해결**
- cancellation이면 상태를 건드리지 않고 return한다. 비취소 결과에만 `isInterestListRetryLoading`을 해제한다.
- 목록이 있는 실패 분기에서 불필요한 `isInterestListLoadFailed = false` 대입을 제거했다.

**교훈**
- 재시도 로딩 플래그는 취소 결과에서 끄지 않는다. 최신 요청 완료에서만 끈다.
- 승격 후보: no
