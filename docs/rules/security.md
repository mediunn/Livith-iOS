# 보안

## Purpose
- 이 저장소에서 AI가 민감한 설정, 인증 정보, 외부 입력, 로그를 안전하게 다루기 위한 보안 규칙을 정의한다.
- 범위 초과 열람과 민감 정보 노출을 막기 위한 작업 기준을 고정한다.

## Scope
- 이 저장소에서 AI가 수행하는 탐색, 분석, 코드 수정, 테스트, 문서 작성 작업에 적용한다.
- 이 저장소의 민감한 설정 파일, 인증 정보, 외부 입력, 로그, 로컬 저장소 처리에 적용한다.
- 다음 용어는 이 문서에서 아래 의미로 사용한다.
- `본문 비열람을 강제하는 민감 설정 파일`: `Tuist/Config/*.xcconfig`와 `Projects/App/Resources/GoogleService-Info.plist`
- `민감한 설정 파일`: 비밀값, 인증 정보, 서비스 설정값, 식별자를 포함하거나 포함할 수 있는 설정 파일
- `민감한 설정 값`: 토큰, 키, 비밀값, 인증 응답 값, 사용자 식별값, 서비스 식별자
- `UserDefaults` 계열 저장소: `UserDefaults.standard`, `UserDefaults(suiteName:)`, App Group 기반 `UserDefaults`, 그리고 이를 감싼 저장 래퍼
- `불필요한 사용자 식별값`: 현재 기능, 세션 유지, UI 표현에 직접 필요하지 않은 이메일, 전화번호, 소셜 계정 식별자, 외부 서비스 user id, 광고 식별자, 푸시 토큰 같은 값
- `보안에 영향을 주는 변경 사항`: 인증, 토큰 저장, 권한, 앱 그룹, `entitlements`, 외부 입력 검증, 로그 정책, 외부 서비스 설정 변경이 포함된 변경

## Do
- 민감한 설정 파일이 필요한 작업에서는 파일 경로와 파일명만 확인한다.
- 민감한 설정 값이 필요한 작업에서는 사용자가 제공한 마스킹 값, placeholder, 복원 불가능한 예시만 사용한다.
- 민감한 설정 파일 확인이 꼭 필요한 경우에는 사용자가 비밀값 자체가 아닌 필요한 키 이름, 구조, 또는 값이 제거된 일부만 제공하도록 요청한다.
- 토큰, 푸시 payload, 사용자 식별값은 응답과 문서에서 복원 불가능한 마스킹 형태 또는 placeholder로만 다룬다.
- 인증 정보와 비밀값은 코드, 테스트, 문서, 예시 스니펫에 하드코딩하지 않는다.
- `UserDefaults` 계열 저장소에는 인증 토큰과 비밀값을 저장하지 않는다.
- 딥링크 URL과 푸시 `userInfo`는 문서나 코드에 명시된 허용 키, 허용 경로, 허용 타입만 검증한 뒤에만 사용한다.
- 허용 목록이 없으면 새 키나 새 경로를 임의로 신뢰하지 않는다.
- 보안에 영향을 주는 변경 사항을 바꾸는 작업 전에는 사용자 확인을 받는다.
- 보안에 영향을 주는 변경 사항은 최종 보고에서 대상과 이유를 함께 적는다.

## Don't
- `*.xcconfig` 파일 본문을 읽지 않는다.
- `Projects/App/Resources/GoogleService-Info.plist` 파일 본문을 읽지 않는다.
- 민감한 설정 파일의 값을 인용하지 않는다.
- 민감한 설정 파일의 값을 요약하지 않는다.
- `FCM Token`을 로그에 출력하지 않는다.
- 푸시 `userInfo` 원문을 로그에 출력하지 않는다.
- 인증 응답 원문을 로그에 출력하지 않는다.
- 토큰, 비밀키, 인증 응답 원문을 `UserDefaults`에 저장하지 않는다.
- 검증하지 않은 딥링크 값으로 화면 이동이나 상태 변경을 수행하지 않는다.
- 검증하지 않은 푸시 payload 값으로 화면 이동이나 상태 변경을 수행하지 않는다.
- 사용자 승인 없이 보안에 영향을 주는 변경 사항을 수정하지 않는다.

## Exception
- 사용자가 특정 파일과 목적을 함께 지정해 허용한 경우에만 필요한 키, 라인, 섹션 범위만 읽는다.
- 한 번의 승인으로 다른 민감 파일이나 다른 목적의 열람을 확장하지 않는다.
- 사용자가 필요한 일부를 직접 제공한 경우에는 제공된 키, 구조, 마스킹된 값, 값이 제거된 라인 범위 안에서만 사용한다.
- 예외적으로 확인한 민감 값도 응답, 로그, 문서, 코드 블록에 원문으로 다시 출력하지 않는다.
- 값이 제거된 샘플 파일만 존재하는 경우에는 그 샘플 파일만 읽는다.
- 빌드나 테스트 도구가 내부적으로 설정 파일을 참조하는 것은 파일 본문 열람으로 보지 않는다.
- 도구 출력에 민감 값이 노출되면 같은 민감 정보로 취급하고 재출력하거나 요약하지 않는다.

## Checklist
- `*.xcconfig` 파일 본문을 읽지 않았는지 확인한다.
- `Projects/App/Resources/GoogleService-Info.plist` 파일 본문을 읽지 않았는지 확인한다.
- 민감한 설정 파일 열람 허용이 파일 단위와 목적 단위로 한정됐는지 확인한다.
- 로그와 응답에 토큰, 푸시 payload, 사용자 식별값 원문이 남지 않았는지 확인한다.
- 민감한 값이 코드, 테스트, 문서에 하드코딩되지 않았는지 확인한다.
- 토큰, 비밀값, 인증 응답 원문, 불필요한 사용자 식별값이 `UserDefaults` 계열 저장소에 들어가지 않았는지 확인한다.
- 딥링크와 푸시 입력값을 문서나 코드에 명시된 허용 목록 검증 없이 사용하지 않았는지 확인한다.
- 보안에 영향을 주는 변경 사항을 바꾸기 전에 사용자 확인을 받았는지 확인한다.
