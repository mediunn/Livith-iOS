# 313 앰플리튜드 이벤트 태그 정리 (archive)

## 결과
- 명세와 iOS 이벤트를 대조하고, 확인된 태그 누락과 오용을 수정했다.
- 최초 세 이벤트의 실제 수신은 사용자가 확인했다. 이후 연결한 홈 관심 콘서트 카드 태그의 실제 수신은 확인하지 않았다.

## 남긴 결정
- 관심 콘서트 설정 확인은 최초 설정 버튼 클릭 시 전송한다.
- 홈 관심 콘서트 카드와 일반 콘서트 셀은 같은 이벤트로 집계한다.
- 구 홈 및 기존 관심 콘서트 변경·삭제 UI 태그는 사용하지 않는다.
- 검색 필터는 현재 앱의 장르를 기준으로 한다.
- 캘린더는 현재 iOS 구현을 유지한다. 월 이동은 이전 기간이 있고 실제 기간이 바뀔 때 전송한다.
- 취향 변경 이벤트의 성공 후 전송 여부는 보류한다.
- 명세에 포함된 `ios_` 접두사와 `comfirm` 오타는 대시보드 호환을 위해 유지한다.

## 컴파운딩
- rules 반영: 없음
- 분리 확인으로 보류 (`architecture` / `security`): device ID 원문 로그 정책 확인
- archive만 유지: 명세와 실제 UI 차이 및 이 이슈의 이벤트 결정
- 반영 없음 / 사유: 공통 규칙으로 승격할 새로운 교훈 없음

## 교훈
- 명세와 현재 UI가 서로 다른 시점에 작성됨 → 이벤트 연결 전에 현재 UI와 기획 결정을 대조한다.
- 버튼 클릭과 저장 성공은 다른 행동임 → 이벤트의 집계 시점을 명확히 구분한다.
