# LIVD-457 7차 스프린트 앰플리튜드 태그 (archive)

## 결과
- 명세서의 태깅 요청 중 네이티브 UI가 있는 이벤트를 연결하고, 삭제 대상 enum을 제거했다. `ios_` 접두사는 기존 중앙 로직을 유지했다.

## 남긴 결정
- raw 값의 `comfirm` 오타는 명세서 그대로 두고, Swift 케이스명만 confirm으로 둔다.
- 캘린더 그리드 3개와 회원가입 배너 태깅은 UI가 없어 제외한다.
- Core에 테스트 타깃을 만들지 않는다. enum 추가와 트랙 호출은 TDD 예외로 진행하고, raw 값은 명세서와 문자 단위로 대조한다.

## 컴파운딩
- rules 반영:
  - `tdd.md` — TDD 전 단위 테스트 타깃을 확인한다. 타깃이 없고 예외 허용 작업이면 타깃을 만들지 않음
- 분리 확인으로 보류: 없음
- archive만 유지:
  - WebView라는 이유만으로 화면 전체 태깅을 불가로 단정하지 않음. 네이티브 필터와 웹 그리드를 나눔
- 반영 없음 / 사유: WebView 경계는 이번 화면의 디테일이라 archive만 유지

## 교훈
- [캘린더 전체를 WebView로 보고 태깅 제외] → 구성 컴포넌트 단위로 네이티브와 웹 경계를 확인한다.
- [EventTag 검증을 위해 Core 테스트 타깃 신설을 검토] → 타깃이 없으면 예외 허용 작업인지 먼저 판정하고, 아니면 TDD를 건너뛰지 않는다.
