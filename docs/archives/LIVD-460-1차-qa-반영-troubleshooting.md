# LIVD-460 [Fix] 1차 QA 반영 - 트러블슈팅

## 기록

### 2026-07-27 - Figma 데스크톱 MCP 접근이 세션 중간에 끊김

**상황**
- 항목 1(정보 요청 화면 툴팁 패딩)을 FR-05 매칭 실패 케이스와 대조하려고 `get_design_context`/`get_screenshot`을 호출.

**문제**
- FR-05 프레임(97:18965, 97:19021)과 툴팁 노드(97:18987)가 "This resource couldn't be accessed / Dev Mode 권한" 오류로 접근 불가.
- 세션 초반 정상 조회됐던 FR-06 프레임(97:20910)도 이후 동일 오류로 재조회 실패.

**원인**
- Figma 데스크톱 앱의 현재 열린 파일/페이지(뷰포트) 또는 Dev Mode 세션 상태가 변경되어, 해당 페이지에 없는 노드는 MCP가 읽지 못함(데스크톱 MCP는 현재 파일/선택 노드 기준으로 동작).

**해결**
- FR-06 프레임을 세션 초반 조회했을 때 확보한 툴팁 좌표(frame 135×37, 버블 `top-0`/`bottom-16.22%` → 높이 31, 화살표 inset 기반 ~14×8)를 사용해 대조. 스크린샷 눈대중이 아닌 디자인 좌표 기반이라 신뢰 가능.
- 툴팁은 FR-05·FR-06에서 동일 컴포넌트(모든 툴팁 노드 135×37 동일 구조)임을 메타데이터로 확인.

**교훈**
- Figma 데스크톱 MCP는 현재 열린 페이지 의존적이다. 여러 프레임을 대조할 때는 세션 초반에 필요한 노드의 design context를 한 번에 확보해 두는 것이 안전하다.
