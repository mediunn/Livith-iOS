# LIVD-317 콘서트 카드 대체 이미지·컴포넌트 배치·검색 상태 정리 (archive)

## 결과
- 웹과 동일한 콘서트 카드 대체 이미지를 적용하고 공통 컴포넌트의 외부 배치 책임을 사용 화면으로 이동했다. 검색 상태의 백그라운드 발행 경고를 수정했다.

## 남긴 결정
- 컴포넌트의 내부 여백·배경·터치 영역은 유지하며, 화면 기준 여백과 전체 영역 배치는 사용하는 화면에서 결정한다.
- 동일 여백은 공통 부모에 선언하되 전체 폭 포스터·가로 스크롤·구분선·그라데이션은 기존 폭을 유지한다.
- 선택 그리드 위 간격은 스크롤 중에도 유지해야 하므로 영역 바깥에 둔다. 아래 여백만 스크롤 콘텐츠에 적용한다.
- 신고 모달의 키보드 회피와 오류 안내 위치는 공용 배치 modifier가 담당한다. 일반 확인 모달은 키보드 높이에 따라 이동하지 않는다.
- 뒤로 가기 스와이프와 추가 컴포넌트 정리는 이번 범위에 포함하지 않는다.

## 컴파운딩
- rules 반영: 없음
- 분리 확인으로 보류 (architecture / security): 없음
- archive만 유지: 웹 에셋 합성, 내부·외부 여백 구분, 스크롤 간격 의도, 비동기 상태 발행, 렌더링·동작 검증의 구분
- 반영 없음 / 사유: 이번 작업의 UI 의도·환경 이슈이거나 기존 MVI·검증 규칙으로 설명되는 내용이므로 새 규칙을 추가하지 않는다.

## 교훈
- [투명 SVG만 이식해 대체 이미지 명암이 사라짐] → 웹 에셋은 실제 CSS 배경과 합성된 모습을 확인한다.
- [개별 사용처에 여백을 반복 지정함] → 외부 여백을 옮길 때 같은 여백을 공유할 공통 부모도 확인한다.
- [고정 상단 간격을 스크롤 콘텐츠 인셋으로 옮김] → 스크롤 중 유지할 간격은 스크롤 영역 바깥에서 지정한다.
- [생성자 괄호만 보고 modifier를 삽입함] → 후행 클로저까지 포함한 View 표현식 경계를 확인한다.
- [send만 MainActor로 격리해 비격리 헬퍼의 발행이 남음] → 실행 격리와 send를 통한 상태 변경을 각각 확인한다.
- [테스트 소스 경로가 Sources로 연결되어 테스트가 실행되지 않음] → 테스트 성공 여부와 실제 실행 건수를 함께 확인한다.
- [PNG 바이트 차이와 빌드 성공만으로 화면 상태를 판단하기 어려움] → 렌더링 비교와 실제 입력·제스처 검증 결과를 구분한다.
- [GitHub 통합 쓰기 권한과 로컬 빌드 경로 접근이 제한됨] → 코드 오류와 환경 권한 오류를 구분하고 승인된 CLI·권한 범위에서 진행한다.
