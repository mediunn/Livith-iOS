# LIVD-320 셋리스트 웹뷰 네이티브 이동 (archive)

## 결과
- 셋리스트 웹뷰에서 기존 네이티브 노래 상세로 이동하고 셋리스트 상단 바를 고정한다.

## 남긴 결정
- 가사 시트가 내비게이션 바를 덮는 기존 경험을 유지하기 위해 노래 상세 전체를 기존 네이티브 화면으로 사용한다.
- 뒤로 가기 제스처 및 별도 팝업 기능은 범위에서 제외한다.

## 컴파운딩
- rules 반영: 없음
- 분리 확인으로 보류 (`architecture` / `security`): 없음
- archive만 유지: 네이티브 시트의 계층과 웹뷰 전환 시 제약.
- 반영 없음 / 사유: 교훈은 이번 화면의 설계와 환경에 한정되거나 기존 규칙으로 충분하다.

## 교훈
- 웹뷰가 네이티브 바 아래로 제한되어 가사 시트가 바를 덮지 못했다 → 웹뷰 전환 전 기존 시트의 계층과 상호작용을 확인한다.
