- Livith-Certificate 변경은 `main`에 직접 반영하고 Livith-iOS의 `main` 대상 hotfix PR로 릴리즈를 실행한다.

## 컴파운딩
- 반영 없음 / 사유: 기존 보안 규칙으로 처리 가능하며 이번 배포에 한정된 설정 수정과 저장소 대상 오해다.
