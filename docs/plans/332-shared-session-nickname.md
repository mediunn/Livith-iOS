# [#332] 홈·프로필의 로그인 사용자 상태 공유

## 배경

홈과 프로필에서 닉네임을 별도 조회 결과로 표시한다. 닉네임 변경과 로그인 세션 수명에 맞춰 표시 원본을 한 곳으로 모은다.

## 목표

- 세션의 닉네임 표시 값은 첫 서버 조회 성공까지 비우고, 실패 시 홈 새로고침으로 재시도한다.
- 저장 성공 응답의 서버 닉네임을 즉시 공유 상태에 반영한다. 편집 초안과 저장 실패는 공유 상태에 반영하지 않는다.
- 로그아웃, 토큰 만료, 계정 전환 시 이전 세션을 종료하고 지연 응답을 무시한다.

## 권한·범위

공유 상태는 닉네임에 한정한다. 기존 디스크 캐시와 푸시 등록, 선호 상태 경로를 유지한다. 기존 API 응답의 값을 반환하도록 닉네임 수정 Repository 계약을 변경한다.

## 작업 항목

- [x] App의 메인 경로 수명에 연결된 Observable 모델을 둔다.
- [x] 메인 탭이 홈·프로필에 표시 값을 전달하고, 홈 새로고침과 닉네임 저장 응답을 모델로 연결한다.
- [x] 기존 조회 결과와 저장 응답이 경합하는 경우 및 세션 종료 동작을 검증한다.
- [ ] Mac에서 앱을 빌드하고 화면 진입·자동 로그인·푸시 등록을 확인한다.

## 영향 범위

App 라우팅, Home의 닉네임 표시와 새로고침, User의 닉네임 표시·수정, Domain 및 Data의 닉네임 수정 계약.

## 주의 사항

로그인에 필요한 토큰 갱신 및 로컬 사용자 확인은 유지한다. 관심 공연과 선호 표시 등 기존 Home 작업을 유지한다.

## 인수인계

`User` 전체의 상태 공유와 디스크 캐시 정책은 후속 작업으로 남긴다.
