# [#337] 관심 콘서트 목록 전환

공연 요청에 적용한 화면별 예외를 관심 콘서트 목록까지 확대한다. 앱에서 조회한 Repository를 Home Environment와 생성자로 전달하고 화면에서 Observable ViewModel을 소유한다.

1. DI 경로와 테스트 대역 주입을 먼저 전환한다.
2. 목록 조회·정렬·다음 페이지 동작을 ViewModel 메서드로 옮긴다.

정렬 전환 실패 시 목록과 커서를 복원하고 오래된 응답을 무시한다. 설정 화면 및 Domain 계약은 이번 범위에서 제외한다. HomeFeature 대상 테스트와 앱 빌드로 검증한다.
