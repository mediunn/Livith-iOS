# [이슈 번호 미지정] 셋리스트 WebView 시제품

## 배경
- 공연 상세의 네이티브 셋리스트 목록에서 웹 셋리스트 상세와 노래 화면을 확인한다.

## 목표
- iOS에서 하나의 WebView로 셋리스트 상세와 노래를 표시하고, 뒤로 가기 시 웹 내부 이동 후 네이티브 목록으로 복귀한다.

## 권한·범위
- 정본: 기존 공연 상세와 목록 유지, 웹 상단바 사용, 인증 연동과 전환 효과 제외, Android 변경 및 원격 푸시 없음.
- 로컬 웹 서버에서 시뮬레이터로 확인한다. 외부 링크는 앱 화면을 대체하지 않도록 처리한다.
- 기존 일반 웹 경로와 동작은 유지한다.

## 작업 항목
- [x] 웹에 앱 진입 및 시작점 종료를 연결하고 기존 셋리스트·노래 화면을 재사용한다.
- [x] iOS 셋리스트 상세 목적지를 WebView에 연결하고 주소와 뒤로 가기, 오류를 처리한다.
- [ ] 사용자 시뮬레이터에서 화면 이동을 검증한다.

## 영향 범위
- Livith-Web 라우터, 셋리스트 상세와 앱 연동.
- Livith-iOS ConcertFeature 내비게이션 및 WebView, 필요한 개발 설정.

## 기술 결정
| 결정 사항 | 선택지 | 결정 | 근거 |
|-----------|--------|------|------|
| 화면 흐름 | 하나 또는 여러 WebView | 하나 | 사용자 결정 |
| 상단바 | 웹 또는 네이티브 | 웹 | 사용자 결정 |
| 인증 | 연동 또는 보류 | 보류 | 사용자 결정 |
| 주소 | 배포 또는 로컬 | 로컬 개발 서버 | 시제품 검증 |

## 주의 사항
- 웹 API의 비로그인 응답 및 로컬 서버 접근은 실행으로 검증해야 한다.
- 브릿지와 외부 링크의 허용 범위를 제한한다.
- 이슈 번호가 아직 지정되지 않아 계획 파일명에 pending을 사용한다.

## 검증 방법
- [x] 웹 빌드: `npm run build` 성공.
- [x] iOS 빌드: `tuist generate --no-open`, `tuist build ConcertFeature` 성공.
- [ ] 시뮬레이터: 목록 → 상세 → 노래 → 상세 → 목록 확인, 불가능하면 이유 기록.
