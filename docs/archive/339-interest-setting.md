# [#339] 관심 콘서트 설정 화면의 의존성 주입과 ViewModel 전환

## 결과와 결정

App에서 콘서트 카탈로그·검색·관심 콘서트 Repository를 조회한다. Home은 기존 관심 콘서트 Environment 키를 재사용하고 설정 화면에 세 의존성을 전달한다. 최초 설정과 변경 화면은 각각 자신의 Observable ViewModel을 소유한다. 프리뷰와 테스트는 대역을 직접 주입한다.

초기 카탈로그와 저장된 선택을 함께 불러오고, 변경 모드의 기존 선택은 마지막 페이지까지 성공한 뒤 반영한다. 기본 목록과 검색 목록의 커서를 분리하고 검색어가 바뀌면 이전 검색을 취소한다. 입력을 지웠다가 같은 검색어를 입력해도 이전 응답이 반영되지 않도록 검색 요청 번호를 검사한다.

## Android 비교

Android 설정 화면의 동일 모드 재진입·화면 이탈 및 검색 실패 테스트를 비교했다. iOS에서는 공연 요청 화면에서 돌아올 때 기존 모델의 선택을 보존하고 설정 화면을 새로 열면 다시 초기화한다. 검색 실패 시 기존 iOS 오류 토스트 흐름을 유지한다.

## 검증

- 생성자 주입만 적용한 시점에 기존 설정 테스트 23건 통과.
- iOS 26.5 시뮬레이터에서 설정 25건과 목록 13건을 각각 3회 반복해 통과. 설정 화면 재표시와 새 진입, 검색어 삭제 후 늦은 페이지 응답을 추가로 검증했다.
- Tuist 프로젝트 생성과 Livith-iOS-Dev 시뮬레이터 빌드 성공.
- 2026-11-26 실기기에서 관심 콘서트 설정 화면이 정상 동작함을 사용자가 확인했다.
